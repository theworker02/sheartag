# sheartag

Shear encode/decode helpers for tag payloads in pipelines.

**Site:** https://theworker02.github.io/sheartag/

## Install / run

```bash
git clone https://github.com/theworker02/sheartag.git
cd sheartag
node src/cli.js
node --test
```
